Where your library is saved

Favorites, lists, and Continue Watching use IndexedDB when available. If IndexedDB is unavailable or blocked, the app automatically uses a localStorage fallback in the same browser profile. Data is not committed to GitHub or synced automatically. Export JSON for backup or transfer.

Ad blocker setup

The player uses a normal unsandboxed iframe so providers do not detect sandbox mode. Blocking is handled by your browser extension.

uBlock Origin for Edge Pie Adblock
When opening index.html directly:
  1. Open edge://extensions.
  2. Open Details for the blocker you use.
  3. Enable Allow access to file URLs.
  4. Reload this player.

Alternatively, run py -m http.server 8080 from the repository and open http://localhost:8080/VidCoreLargePlayer/.
